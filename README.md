# mdVü demo vault

A ready-made Obsidian vault for trying out [mdVü](https://github.com/m3repo/mdvu), the lean Markdown reader for Windows, or any other Markdown tool. Everything in here is free to use: public domain texts, open data and our own additions under CC BY 4.0.

Open the folder in mdVü (*File → Open folder*, or drop it on the window) and start with [Welcome](Welcome.md). It works just as well as a vault in Obsidian.

## What's inside

| Folder | Content | Good for testing |
|---|---|---|
| `Fairy Tales/Grimm/` | 198 tales and 10 children's legends of the Brothers Grimm in Margaret Hunt's English translation (1884), grouped in folders up to four levels deep, with wikilinks between them; every tale with section headings, a short summary and a table of its characters; the best-known tales with flowcharts and sequence diagrams; pages for characters, statistics, places and things | folder view, outline, scrolling, wikilinks, links to headings, search in files, callouts, frontmatter, charts, emoji, highlights, comments, very wide tables |
| `Data/` | *planned:* large tables from open data (GeoNames, OurAirports) | wide and long tables, print fitting, PDF |
| `Specs/` | the WHATWG HTML, DOM and Infra standards as Markdown, converted from the original web pages with mdVü; the HTML Standard alone is 6.6 MB and 82,000 lines, with 1,600 callouts and 5,300 links into the other two files. The settings file of the conversion, `mdvu-converter.yaml`, lies next to them. *Planned:* a file of more than 50 MB for load tests, generated by a script and not stored in Git | very large files, piecewise loading, search in large files, links to headings in other files, callouts, code blocks, long outlines |

## Tales not included

A few tales of the collection are deliberately left out because of their racist content. If you need them, the complete text is available from [Project Gutenberg](https://www.gutenberg.org/ebooks/5314).

## How it was made

The tales are generated by a script from the Project Gutenberg text. Section headings, summaries and character data come from an AI model (Claude Haiku) that read every tale once; the results were checked for consistency, not by hand. The story flowcharts and dialogues of the best-known tales were written by hand. The illustrations of the best-known tales were made with an AI image generator in the style of a torn-paper collage.

The three standards in `Specs/` were saved from `html.spec.whatwg.org`, `dom.spec.whatwg.org` and `infra.spec.whatwg.org` and converted with mdVü (*Tools → Convert HTML file to Markdown*, or `mdvu.exe /convert page.html`). `Specs/mdvu-converter.yaml` tells the converter which classes become callouts, which elements to leave out, how links between the three pages are rewritten, and what the header and the note at the top of each page contain. Each page names its source, the commit it was taken from and the changes made. They are unofficial copies; the authoritative text is the original.
